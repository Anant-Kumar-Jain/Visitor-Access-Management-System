## 1. Board Columns & Workflow Stages
- **Backlog:** Prioritized user stories awaiting sprint allocation.
- **Sprint To-Do:** Tasks committed for current 1-week sprint.
- **In Progress:** Active implementation by assigned team member.
- **Code Review / PR:** Code changes undergoing peer review.
- **QA Verification:** Automated tests and manual validation.
- **Done:** Fully merged into `main` branch with passing CI.
