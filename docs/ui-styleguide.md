**Lead UI Designer:** Ashish Kumar Swami (`ashishswami227@gmail.com`)

## 1. Component Rules
- **Buttons:**
  - Primary Action: `.btn-primary` (Navy `#1e3c72`, border-radius 6px, hover brightness 110%)
  - Secondary Action: `.btn-outline-secondary` (Border 1px solid `#ced4da`)
  - Danger Action: `.btn-danger` (Crimson `#dc3545` for rejection or emergency lockdown)
- **Badges:**
  - `badge-pending`: Amber `#fff3cd` background with dark amber `#856404` text.
  - `badge-approved`: Forest green `#d4edda` background with `#155724` text.
  - `badge-rejected`: Light red `#f8d7da` background with `#721c24` text.
- **Form Inputs:**
  - Border: 1px solid `#dee2e6`
  - Focus Ring: 3px semi-transparent outline `#2a529840`
  - Floating Labels: Standardized across authentication views for modern usability.
