## 1. Quality Assurance Strategy
- **Unit Testing:** JUnit 5 and Mockito isolating service classes and validators.
- **Integration Testing:** Spring Boot `@SpringBootTest` testing web controllers, repositories, and security filter chains.
- **Security Testing:** OWASP Top 10 automated vulnerability screening.
- **Target Coverage:** JaCoCo instruction coverage $> 85\%$.
