## 1. Standard Test Case Template Schema
- **Test ID:** Unique identifier (e.g. `TC-SEC-01`)
- **Module:** Target functional subsystem
- **Preconditions:** Initial environment state
- **Test Data / Input:** Specific test payload parameters
- **Execution Steps:** Sequential actions performed
- **Expected Result:** System behavior per specification
- **Actual Result:** Observed system response
- **Status:** PASS / FAIL / BLOCKED
