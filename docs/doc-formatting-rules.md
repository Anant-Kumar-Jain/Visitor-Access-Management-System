## 1. Style & Formatting Standards
- All technical documentation must be authored in GitHub Flavored Markdown (GFM).
- Every document must feature author attribution, date, and version identifier.
- Code blocks must declare explicit language syntax highlighting (e.g. ````java`, ````sql`, ````bash`).
