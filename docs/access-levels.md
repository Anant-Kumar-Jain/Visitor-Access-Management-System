## 1. Access Level Hierarchy
VAMS defines two fundamental access clearance levels:

1. **`PUBLIC` Access Level:**
   - **Permitted Users:** All approved visitors, guests, contractors, and staff.
   - **Associated Zones:** Campus Main Entrance, General Reception, Visitor Cafeteria, North Lobby.
   - **Verification Requirement:** Valid, unexpired visitor access pass token.

2. **`RESTRICTED` Access Level:**
   - **Permitted Users:** Authorized personnel, executive management, and specifically escorted contractors.
   - **Associated Zones:** Data Center / Server Vault, High-Voltage Substation, Executive Boardrooms, R&D Laboratories.
   - **Verification Requirement:** Explicit clearance authorization granted by Facility Manager upon pass application.
