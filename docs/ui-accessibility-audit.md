# Web Content Accessibility Guidelines (WCAG 2.1 AA) Audit

**Author:** Ashish Kumar Swami (`ashishswami227@gmail.com`)  

---

## 1. Accessibility Audit Summary
- **Color Contrast:** All body text meets or exceeds 4.5:1 ratio against background.
- **Keyboard Navigation:** Full interactive flow traversable via Tab / Shift+Tab keys.
- **Screen Reader Support:** Form controls include descriptive `aria-label` and `aria-describedby` attributes.
