# Visitor Access Management System (VAMS)

[![Java CI with Maven](https://github.com/Anant-Kumar-Jain/Visitor-Access-Management-System/actions/workflows/maven.yml/badge.svg)](https://github.com/Anant-Kumar-Jain/Visitor-Access-Management-System)
[![Version](https://img.shields.io/badge/version-1.0.0--RELEASE-blue.svg)](https://github.com/Anant-Kumar-Jain/Visitor-Access-Management-System)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

An enterprise-grade, contactless visitor access control application built with **Java 17**, **Spring Boot 3**, **Thymeleaf**, **MySQL 8.0**, and **Google ZXing QR Engine**.
