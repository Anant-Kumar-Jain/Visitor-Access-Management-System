# UI Typography, Color Palette & Design Tokens

**Lead UI Designer:** Ashish Kumar Swami (`ashishswami227@gmail.com`)  
**Design System:** VAMS Clean Corporate Design System (Bootstrap 5 customized)  

---

## 1. Color Palette Tokens

- **Primary Brand Navy:** `#1e3c72` (Headers, main navigation, primary action buttons)
- **Secondary Accent Blue:** `#2a5298` (Hero gradients, hover highlights, active links)
- **Success Forest Green:** `#28a745` (Approved badges, entry granted banners, valid scans)
- **Warning Amber:** `#ffc107` (Pending badges, clearance warning notices)
- **Danger Crimson:** `#dc3545` (Rejected badges, entry denied banners, passback violations)
- **Neutral Dark:** `#212529` (High-contrast body text on light backgrounds)
- **Neutral Light:** `#f8f9fa` (Background card surfaces, subtle borders)

---

## 2. Typography Scale
- **Primary Typeface:** `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
- **Heading 1 (`h1`):** 2.25rem (36px), font-weight 700, letter-spacing -0.02em
- **Heading 2 (`h2`):** 1.75rem (28px), font-weight 600
- **Body Text:** 1.0rem (16px), line-height 1.6, font-weight 400
- **Badge / Metric Small:** 0.85rem (13.6px), font-weight 600, text-transform uppercase
